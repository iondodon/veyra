Administrator diagnostics

Available only at localhost on the computer running Veyra. Veyra stays unprivileged. This action uses the system’s authentication dialog to run nft list ruleset once as administrator. It does not change firewall rules or grant ongoing root access.

Never enter a password in chat or a web form. Enter it only in the operating system’s authentication prompt on this PC. A desktop polkit authentication agent must be running. Cancelling the prompt cancels the action.

Results stay in memory until the next inspection or restart. They are not sent to the model automatically. Firewall rules can contain network addresses; review before sharing.
