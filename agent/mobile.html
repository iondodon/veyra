Veyra on iPhone with Expo Go

A React Native chat client using native controls, running inside the free Expo Go app. No Mac, paid Apple account, or publishing required. It is not a standalone Swift app.

Start development mode

  1. Install Expo Go from the iPhone App Store.
  2. Keep the phone and Veyra computer on the same trusted Wi-Fi. Veyra must remain running.
  3. From the Veyra project directory, start the mobile development server:
    cd agent/mobile
npm ci
npm start
    Node.js 22 or newer and npm are required. Expo displays a QR code. Scan it with the iPhone Camera and open it in Expo Go. Allow local network access if prompted. Keep this development server running; Ctrl+C stops it without stopping Veyra.
  4. In the phone app, enter http://COMPUTER_PRIVATE_IP:3000 and your Veyra network password. Do not use localhost, which refers to the phone. Username is fixed to veyra. The initial password is veyra; change it in web Chat → Settings before use. The app stores connection details in iOS secure storage, not chat credentials.

Try it

Send a message, watch replies appear automatically, and approve or deny a command request. Approving shows a confirmation with the command text. Stale approvals become disabled. The app shows this session’s messages, command output, and attached images, with plain-text formatting. It polls the existing server API; replies appear when the server publishes them, not token-by-token.

Privacy and limits

Keep service sign-in and private API key management in web Settings on the Veyra host. API keys never belong in the phone connection form. “Forget connection” clears the saved address, network password, and draft from the phone; it does not disconnect the model service. Use web Settings → Disconnect current service for that.

HTTP sends messages and the network password without encryption. Use only a trusted private network, or arrange an encrypted private tunnel. Do not forward Veyra or Expo ports to the public internet. Expo’s development tunnel, if used, does not make Veyra’s API reachable or encrypted.

If connecting fails, check the computer’s private IP, password, local network permission, and firewall access to Veyra port 3000 and Expo port 8081. Update Expo Go if it reports an incompatible SDK. Reopen the QR code after restarting Metro. Restart Veyra to test reconnection: the phone keeps its draft while refreshing session state. Earlier sessions are not loaded by the existing API.

The source is in agent/mobile. Development checks: npm test, npm run check, and npm run export:ios. Physical iPhone testing requires your phone; bundle checks are not a substitute.
